
# Vivere atque FruiT

Osobní digitální prostor pro znalosti, nápady, nástroje a projekty.

## Princip

- Pevný a přehledný základ.
- Modulární struktura, kterou lze rozšiřovat.
- Postupný vývoj bez zbytečné složitosti.
- Tmavý design s červenými a zelenými akcenty.
- Důraz na přehlednost a možnost budoucího rozšíření.

## Soubory

- `index.html` — struktura stránky.
- `style.css` — vzhled a rozvržení.
- `script.js` — chování a správa polic.

## Aktuální verze

0.1 — základní rozhraní a uživatelsky přidávané police.

## Ukládání

Vlastní police se ukládají do místního úložiště prohlížeče.
Zatím nejsou synchronizovány mezi zařízeními.

## Další směr

- Vylepšení struktury a navigace.
- Bezpečnější zálohování dat.
- Možnost exportu a importu obsahu.
- Příprava na instalovatelnou aplikaci.
- Budoucí rozšíření o vlastní znalostní systém a AI.
